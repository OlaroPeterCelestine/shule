# Little Royals School OS (Angular)

Angular 22 app for Little Royals Kindergarten & Primary School management.

## Run

```bash
npm install
npm start
```

Open [http://localhost:4200/](http://localhost:4200/). Sign in with a demo role, or any email and password.

## What’s included

Standalone routed pages for login, dashboard (role views), students, admissions, HR, curriculum, academics, assessments, finance, transport, library, hostel, visitors, communication, meetings, welfare, promotion/alumni, documents, reports, AI assistant, and system/audit — plus toasts, modals, and CSV/document generation from the original prototype.
